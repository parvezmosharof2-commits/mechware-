## H4a — console first-load JS back under 170 kB (frontend only, not committed)
Cause: every console route that imported a Radix `Dialog` (directly, or through `StepUpDialog` / `ReasonDialog`) carried the dialog chunk (~14 kB gzip plus helpers) in its first load. Fix: the dialog code now loads when a dialog is first opened (`React.lazy`, not `next/dynamic`, which counted the chunk in the first load; see the D4.17 HANDOFF). `src/lib/lazyDialog.tsx` mounts the lazy dialog on first `open` and keeps it mounted, so close animation and focus return behave as before. `StepUpDialog` and `ReasonDialog` keep their names and props (the real code is in `*Impl.tsx`); the inline confirm / form dialogs of Companies, Credit adjustment detail, Shipping zone editor, Price list editor, Price list decision panel and Product panels use the new `Modal` + `ModalFooter` (`components/Modal.tsx`, same markup, test ids kept through `contentTestId` / `descriptionTestId`). No behaviour or a11y change.
