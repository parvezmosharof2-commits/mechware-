## HANDOFF (E1.1)
**Moved:** the catalog domain no longer references the cart domain.
- `ProductVariant.ToCartFacts(...)` is gone; the cart builds the snapshot: `VariantFacts.From(variant, sellable, unitNetMinor, available)` (in `CartEngine.cs`; the cart knows the catalog, not the reverse).
- `MaxQuantityPerLine` / `MaxCartLines` now live in `Domain/Common/OrderLimits.cs`; `CartEngine.MaxQuantityPerLine` / `MaxLines` alias them (no behaviour change). `ProductVariant.SetOrderUnits` and `CatalogImportValidator` use `OrderLimits`.
- Ratchet: `ModuleBoundaryTests.DomainCatalog_DoesNotReferenceDomainCart` (Mono.Cecil over the Domain assembly, no allow-list). Caveat: Cecil sees method/type references, not inlined `const` values, so the const case is guarded by convention (use `OrderLimits`), the type case by the test.

**Contract (`Mechware.Application.Cart`):** `CartOwner` (readonly struct; only `ForUser(Guid)` and `FromValidatedGuestToken(GuestCartId)`; `StoreKey` = `cart:u:{N}` / `cart:g:{N}`), `GuestCartId`, `StoredCart(Cart, ETag)`, `ICartStore` { `GetAsync`, `SaveAsync(owner, cart, expectedETag)` returning `(Saved|Conflict, ETag)` as compare-and-set (null expected = must not exist), `DeleteAsync` idempotent }, `ICartStore.GuestTtl` 7 d / `UserTtl` 30 d (sliding), `IGuestCartTokenService` { `Issue(GuestCartId)`, `Validate(string?) -> GuestCartId?` null on any bad token }.

**Notes for E1.2 (Opus review):**
- Implement the CAS atomically (Lua script or WATCH/MULTI); ETag can be a hash/counter, opaque to callers. `Cart.Version` exists in the domain record but is not the ETag.
- Store must re-check limits (`OrderLimits`) as defence in depth; expired = absent.
- Token: HMAC with a rotating key, expiry inside the signed payload, constant-time compare, HttpOnly + SameSite cookie; `Validate` must never throw or leak the reason. Guest id is server-minted (`GuestCartId.New()`), never client-chosen.
- TTL values are a proposal; confirm. Merge-on-login (E1.4) should delete the guest cart after a successful CAS of the user cart.
