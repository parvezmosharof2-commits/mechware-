**Moved (backend only, no endpoints, no tariff data anywhere):** `backend/src/Mechware.Domain/Shipping/` (`ShippingRateCard`, `ShippingZone`, `ShippingCalculator`), `backend/src/Mechware.Application/Shipping/IShippingRateProvider.cs`, `backend/src/Mechware.Infrastructure/Shipping/ShippingRateProvider.cs` (AsNoTracking, split query, active zones only), `backend/src/Mechware.Infrastructure/Persistence/Configurations/ShippingConfigurations.cs`, migration `AddShippingZones` (tables `shipping_zones`, `shipping_zone_districts`, `shipping_rate_bands`; empty). Tests: `~Mechware.UnitTests.Shipping` and `~Mechware.IntegrationTests.Shipping`.

**Model.** Zone = code, EN/BN name, active flag, a set of **district** ids (`bd_locations` rows with level `district`; FK, restrict) and one rate card. Rate card = weight bands `(maxGrams, feeMinor)` + optional free-shipping threshold (subtotal >= X) + optional heavy-unit grams + optional oversize side mm + fee cap. A district can be in only one zone: the primary key of `shipping_zone_districts` is `district_id` (DB refuses), the domain refuses a duplicate in one zone, the calculator refuses a district found in two zones passed to it. The existing `BdLocation.ShippingZone` text column (`inside_dhaka` ...) is NOT used by this model; E8.4 may drop or ignore it.
**Calculator** `ShippingCalculator.Calculate(zones, districtId, lines, orderSubtotalMinor)` returns `Priced(ZoneId, PerSeller[], TotalMinor, FreeShippingApplied)`, `QuoteOnly(Reasons[])` or `NoZone`; throws `ValidationException` for no weight (`NO_WEIGHT`), quantity <= 0, empty order, negative subtotal.
- Units: weight whole grams (`ShippingLine.GramsFromKg` = ceiling of `ProductVariant.WeightKg * 1000`), sides whole mm (`MmFromCm` = ceiling of cm * 10; sides live on `Product`, not the variant). Money poisha, no floats.
- One parcel group per seller: seller weight = sum(qty * unit grams); fee = first band with `weight <= maxGrams` (exactly maxKg stays, +1 g moves up). Heavier than the last band = `QuoteOnly` (`ABOVE_LAST_BAND`), never a guessed fee.
- Free shipping: order subtotal >= threshold makes every seller fee 0 (priced, `FreeShippingApplied`). Quote-only wins over free.
- Quote-only rules: any single unit > `HeavyUnitGrams` (`HEAVY_ITEM`), any side > `OversizeDimensionMm` (`OVERSIZE_ITEM`; unknown sides are not oversize), or above last band. Reasons carry variant/seller ids. The brief has no product-level heavy flag, so this is a configurable rule, as asked.
- Total = exact sum of per-seller fees (computed once); fee <= cap; band fees must be non-decreasing and <= cap (card validation), so heavier is never cheaper.
- `QuoteOnly` is the whole order, not per seller (one decision for staff).
