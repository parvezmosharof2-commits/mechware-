## HANDOFF C1.7 (2026-11-16) staff product management API (parts 1-3, 5, 6; part 4 attributes left)
**Endpoints (all `catalog.manage`, actor = signed-in user):** `GET /admin/products?q&status&brandId&categoryId&supplyStatus&sellerId&page&pageSize` (<= 50, drafts included, deleted excluded, q = ILIKE title EN/BN, slug, SKU, part number, wildcards escaped; 2 SQL queries whatever the page size) · `GET /admin/products/{id}` (titles, short descriptions, `descriptionHtml`, brand, category + path, seller store, status + `allowedTransitions`, dimensions, `rowVersion`, variants with weight/price/status/sale/MOQ/pack) · `PUT /admin/products/{id}` (titles, short descriptions, description HTML, brand, category, optional L/W/H cm; `expectedVersion` required; slug never changes; markup outside the sanitiser allow-list is refused 400 with the field) · `PUT /admin/products/{id}/variants/{variantId}` (`weightKg` > 0, <= 1000, <= 3 decimals; `priceMinor` 1..MaxUnitPrice; `status` active|inactive; null = unchanged; audit row `catalog.variant.price_changed` with old and new) · `POST /admin/products/{id}/publish|archive|restore` (`{expectedVersion}`; 409 with `INVALID_PRODUCT_TRANSITION`, `NO_MEDIA`, `NO_VARIANT`, `NO_SELLABLE_VARIANT`).
